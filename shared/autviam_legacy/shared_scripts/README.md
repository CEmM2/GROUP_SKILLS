# Archived AutViam shared scripts

These scheduler, gate, routing, and GitHub-plumbing scripts are retained only for explicit legacy
invocation during the compatibility window ending **2026-10-01**.

They are included in the published `skills/` subtree solely to support explicit legacy invocation,
but are excluded from active skill registration and the AutViam or AutViam_C façade paths. Do not
copy them back into those active paths, and do not use them as an automatic or silent fallback when
Whatter or the required profile is unavailable.
